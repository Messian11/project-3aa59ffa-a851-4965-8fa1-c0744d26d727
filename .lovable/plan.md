# Финальная доработка темы Zaymi Online v3.4

Прогон по всем страницам сайта https://zaymi-online.ru/, фикс всех визуальных багов и сборка финального архива **`zaymi-online-v3.4-FINAL.zip`**.

## Что будет исправлено

### 1. Звёздочки рейтинга наезжают на названия МФО
**Проблема (видно на скрине каталога):** `Кредито24★★★★`, `EzaemOnline★★★`, `ProstoZaim★★★★` — звёзды лезут поверх названия.

**Причина:** в карточках МФО заголовок и блок звёзд лежат во flex-контейнере без `min-width:0` и `flex-shrink`, длинные названия не переносятся, звёзды абсолютно позиционированы рядом.

**Решение** — правка `assets/css/main.css` + `conversion.css`:
- Заголовку карточки `.mfo-card__title`: `min-width: 0; word-break: break-word; padding-right: 8px;`
- Блоку звёзд: `flex-shrink: 0; white-space: nowrap;`
- На карточках в каталоге/городах/суммах — перенос звёзд под заголовок при ширине < 360px (`flex-wrap: wrap`)
- Уменьшение размера звёзд до 14px на компактных карточках

### 2. На главной нет картинок к статьям блога
**Проблема:** на превью (Lovable) картинки тянутся, на залитой WP-теме — пустые градиенты.

**Решение** — правка блока вывода блога на главной (`inc/shortcodes.php`, шорткод `[zaymi_blog_home]` или аналогичный):
- Добавить вывод `the_post_thumbnail('medium_large')` с fallback на градиентный плейсхолдер
- CSS: `aspect-ratio: 16/9; object-fit: cover; border-radius: 12px 12px 0 0`
- Hover-эффект `scale(1.05)`

### 3. Прочие баги по страницам (аудит браузером)
Пройдусь по ключевым страницам через browser-инструмент и зафиксирую найденное:
- `/` — главная
- `/mfo/` — каталог
- `/mfo/{slug}/` — карточка МФО
- `/goroda/ekaterinburg/` (упомянута пользователем)
- `/situations/{slug}/`, `/summa/{slug}/`
- `/blog/`, `/blog/{slug}/`

Типовые ожидаемые проблемы (фиксим за один проход):
- Кривое выравнивание hero-CTA на мобильном
- Длинные слова без `overflow-wrap: break-word`
- FAQ-аккордеон без анимации
- Хлебные крошки без отступа сверху на term-страницах
- Sticky-CTA перекрывает футер
- Slug-фильтры без активного состояния

### 4. Дополнительные улучшения «от себя»
- **Skeleton-загрузка** карточек МФО (CSS-only, без JS)
- **Trust-бейджи** в шапке header.php (ЦБ РФ, СРО) — мелкая иконка
- **Микроразметка BreadcrumbList** на term-страницах (если ещё нет)
- **Lazy-loading** для всех `<img>` через фильтр `wp_lazy_loading_enabled` (включён, но проверить логотипы МФО)
- **Preconnect** к шрифтам и CDN в `<head>`
- **Print-стили** для статей блога

### Workflow
1. **Browser-аудит** — пройду по 7 ключевым страницам live-сайта, сделаю скриншоты, выпишу баги
2. **Фиксы CSS+PHP** — все правки
3. **QA** — повторный обход через browser, проверка фиксов на превью
4. **Сборка архива** — `zaymi-online-v3.4-FINAL.zip` в `/mnt/documents/`
5. **Changelog** — короткий `CHANGELOG-v3.4.md` с списком фиксов

### Деплой пользователем
1. Темы → Загрузить → выбрать v3.4 → "Заменить активную"
2. Настройки → Постоянные ссылки → Сохранить (×2)
3. Очистить кеш (если стоит плагин кеширования)

## Что НЕ входит в этот заход
- Переписывание архитектуры (тема стабильная, v3.3 работает)
- Новые типы контента (CPT, таксономии)
- Изменение дизайн-токенов (цвета/шрифты остаются)

Если найду критичный баг, который требует структурной переделки — напишу отдельным сообщением и спрошу разрешения, прежде чем включать в архив.
