## Аудит страницы #5 — Ситуация (`/situations/srochno`)

Сверил текущую реализацию (`src/routes/situations.$slug.tsx`) с эталонным скрином.

### ✅ Что совпадает с эталоном
1. **Hero** — eyebrow «Подборка МФО», H1 с акцентом «срочно за 5 минут» в оранжевом, подзаголовок, 4 trust-чипа (5 минут / 93% одобрений / Карта 24/7 / Без справок).
2. **«Почему эти МФО выдают деньги срочно?»** — 4 карточки преимуществ в сетке.
3. **«МФО с моментальным решением»** — заголовок + ссылка «Все МФО →» справа, сетка карточек 4×N.
4. **«Что делать, если деньги нужны срочно, а отказали?»** — 5 шагов с номерами + иконками + советом-callout снизу.
5. **«Похожие подборки»** — чипы-ссылки на другие ситуации.
6. **SEO-блок** — H2 + H3 секции, маркированный список, красный warning-callout «Важно».
7. **FAQ** — аккордеон с 6 вопросами.
8. **Hub «Полная навигация по сайту»** — тёмный градиент, 4 колонки.

### ⚠️ Проблемы (общие с каталогом и городом)

**A. Карточки МФО — рейтинг переносится / неравная высота** (та же проблема, что флагнули на стр. 2 и 4)
- В `CatalogSection` (строки 442–446) блок рейтинга `<div className="text-right">` не имеет `shrink-0` / `min-width` → при длинном имени МФО («EzaemOnline», «MoneyMan») рейтинг и подпись `(reviews)` ломаются.
- Бейджи (`mt-3`, строки 453–467) имеют разное число (1–2 шт), из-за чего блок данных и кнопки «Получить займ» / «Обзор» не выровнены по горизонтали в строке.

**B. Мобильная адаптация заголовка каталога**
- Ссылка «Все МФО →» (стр. 430–432) скрыта на мобиле (`hidden md:inline`). На мобилке нужен дубликат снизу секции (кнопка во всю ширину), иначе пользователь не уходит в каталог.

**C. Шаги «Что делать при отказе» — мобильный layout**
- Сетка `md:grid-cols-[64px_56px_1fr]` на мобилке схлопывается в 1 колонку, но номер (`64px`) и иконка (`56px`) рендерятся друг под другом по центру строки. В эталоне на мобиле это компактнее: номер слева, иконка справа в одну строку, заголовок ниже.

### 🔧 Планируемые фиксы (v3.6.0)

```css
/* A. Стабилизация карточки МФО (применяется ко всем сеткам: каталог, город, ситуация) */
.zf-card-rating { flex-shrink: 0; min-width: 88px; white-space: nowrap; text-align: right; }
.zf-card-badges { display: flex; flex-wrap: wrap; gap: 6px; min-height: 28px; }
@media (min-width: 1024px) { .zf-card-badges { min-height: 56px; } }
.zf-card { display: flex; flex-direction: column; height: 100%; }
.zf-card-cta { margin-top: auto; }
```

В `situations.$slug.tsx`:
- Строка 442 — добавить класс `zf-card-rating` на `<div className="text-right">`.
- Строка 453 — добавить класс `zf-card-badges` к контейнеру бейджей.
- Строка 437 — добавить класс `zf-card` к `<article>`.
- Строки 476–485 — обернуть блок CTA в `<div className="zf-card-cta">…</div>`, чтобы кнопки были прижаты к низу при разной длине контента.

**B. Кнопка «Все МФО» на мобиле:**
- После `</div>` сетки карточек (строка 488) добавить мобильный CTA:
```tsx
<Link to="/mfo" className="mt-8 flex h-12 w-full items-center justify-center rounded-pill border border-brand-line bg-white text-sm font-bold text-brand-blue shadow-card md:hidden">
  Смотреть все МФО →
</Link>
```

**C. Мобильный layout шагов отказа:**
- Заменить `grid-cols-[64px_56px_1fr]` на адаптивный:
```tsx
className="flex flex-col gap-4 rounded-2xl border ... md:grid md:grid-cols-[64px_56px_1fr] md:items-center md:gap-5"
```
- На мобиле обернуть номер+иконку в `<div className="flex items-center gap-3 md:contents">`, чтобы они шли в одну строку на узком экране.
