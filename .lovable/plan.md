
# Zaymi Online v3.5 — финальный визуальный аудит и фиксы

Пройдусь браузером по live-сайту https://zaymi-online.ru/ (главная, /mfo/, карточки МФО, /goroda/*, /situations/*, /summa/*, /blog/), соберу все баги и выкачу архив **`zaymi-online-v3.5-FINAL.zip`**.

## Подтверждённые баги из ваших скринов

### 1. Бейджи под названиями МФО ломают сетку (десктоп)
**Скрин 1** — «Первый займ 0%», «На карту любого банка», «Деньги за 7 минут на карту», «С плохой КИ» сейчас лежат в той же flex-колонке что и название → растягивают карточку по высоте, перенос в 2-3 строки, ломается выравнивание блоков «Сумма / Срок / Ставка / Одобрение».

**Решение:**
- Вынести бейдж из колонки заголовка в отдельный ряд **под** заголовком (не рядом с лого).
- Ограничить высоту бейджа 1 строкой: `max-width: 100%; overflow: hidden; text-overflow: ellipsis; white-space: nowrap;` + `title="..."` для полного текста на hover.
- Уменьшить размер бейджа на десктопе: `font-size: 11px; padding: 4px 10px;`.
- Сделать единую фиксированную высоту области заголовка: `min-height: 56px` для всех карточек в сетке → визуально ровные ряды.
- На мобиле (<640px) — оставить как сейчас (там ок).

Файлы: `assets/css/main.css`, `inc/shortcodes.php` (разметка `.zf-card-head`).

### 2. Мобильное меню в карточке МФО (Скрин 2)
Бургер-кнопка слева, но при открытии меню разъезжается / нет padding-top, breadcrumbs «Главная > Каталог МФО > Кредито24» идут вертикально вместо строки с переносом по `›`.

**Решение:**
- Breadcrumbs: `display: flex; flex-wrap: wrap; gap: 6px; align-items: center` + разделитель `›` через `::after` псевдоэлемент.
- Mobile-меню overlay: `position: fixed; inset: 0; background: #fff; padding: 24px; z-index: 60` + кнопка закрытия в правом верхнем углу.
- Убрать дубли стрелок `>` между крошками.

Файлы: `header.php`, `assets/css/main.css`, `assets/js/app.js` (toggle).

### 3. Блоки внизу каталога МФО (Скрин 3)
«Займы по сумме / Займы по городам / Подборки / С этим ищут» — теги болтаются без визуальной группировки, секция «С этим ищут» с тёмным фоном выделяется грубым прямоугольником без скруглений и отступов.

**Решение:**
- Обернуть каждую группу в карточку: `bg-white border rounded-2xl p-6 shadow-sm`.
- Заголовкам групп — `text-sm uppercase tracking-wide text-brand-muted font-semibold mb-3`.
- Тегам — единый стиль pill с hover (`hover:bg-brand-soft hover:border-brand-blue`).
- «С этим ищут» — переписать с `bg-slate-900` на `bg-brand-soft` (светлый), теги белые с тенью.
- Активный тег («Краснодар» зелёный) — оставить, добавить такое же поведение остальным при выборе.

Файл: `inc/shortcodes-extra.php` (`[zaymi_internal_links]`, `[zaymi_lsi]`), `assets/css/seo.css`.

### 4. Фильтр «Особенности» обнуляет выдачу (Скрин 4)
На `/summa/zaim-100000/` при клике на чекбокс (Без отказа / С плохой КИ / Первый займ 0% и т.д.) показывает **0 офферов**, хотя в каталоге эти МФО есть.

**Причина (предположение из кода):** фильтр шлёт slug чекбокса (`bez-otkaza`), а в meta МФО хранится массив с другими ключами (`no_refusal`, `bad_credit`). Mapping не совпадает.

**Решение:**
- В `inc/shortcodes.php` (фильтр каталога) добавить map `slug→meta_key`:
  ```
  'bez-otkaza' => 'feat_no_refusal',
  's-plohoy-ki' => 'feat_bad_credit',
  'pervyy-zaym-0' => 'feat_first_zero',
  'mgnovennoe-reshenie' => 'feat_instant',
  'bez-spravok' => 'feat_no_docs',
  'pensioneram' => 'feat_pensioners',
  'studentam' => 'feat_students',
  ```
- Если у МФО нет ни одного из этих meta — fallback на поиск по `tax_query` тегам.
- Если фильтр пустой → вернуть полный список (сейчас, видимо, AND с пустым массивом = 0).
- Добавить состояние «Ничего не найдено» с кнопкой «Сбросить фильтры».

Файлы: `inc/shortcodes.php`, `inc/shortcodes-extra.php`.
