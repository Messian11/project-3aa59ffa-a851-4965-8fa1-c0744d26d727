## ЧАСТЬ 1 — Подготовка хостинга и чистка старого WP <a id="часть-1"></a>

### 1.1. Бэкап текущего сайта (ОБЯЗАТЕЛЬНО)

Прежде чем что-то делать — **сделай полный бэкап**. Если облажаешься — откатишься за 5 минут.

**Способ 1 — через плагин (проще):**
1. WP-админка → Плагины → Добавить новый → ищи `UpdraftPlus`
2. Установить → Активировать
3. Настройки → UpdraftPlus → "Создать резервную копию сейчас"
4. Скачай оба архива (Database + Plugins+Themes+Uploads) на свой комп

**Способ 2 — через хостинг:**
- Beget / Timeweb / Reg.ru: в панели хостинга → "Резервные копии" → "Создать"
- Скачай дамп БД (`.sql`) и архив `wp-content/`

### 1.2. Чистка старой темы и лишних плагинов

**Удали ВСЁ, что относится к старой теме:**

```
WP-админка → Внешний вид → Темы → удали все темы кроме одной (например Twenty Twenty-Four — для подстраховки)
```

**Удали лишние плагины** (они конфликтуют с нашей темой). Оставь ТОЛЬКО:
- ✅ **Advanced Custom Fields PRO** (нужен теме, обязательно)
- ✅ **UpdraftPlus** (бэкапы)
- ✅ **Wordfence** или **Limit Login Attempts Reloaded** (защита от брута)

**Удали:**
- ❌ Yoast SEO / Rank Math / All in One SEO — у нашей темы свой SEO-движок (Schema, sitemap, OG, robots.txt). Yoast будет дублировать и ломать.
- ❌ Любые конструкторы (Elementor, WPBakery, Divi) — сломают шорткоды
- ❌ Кэш-плагины (WP Super Cache, W3 Total Cache) — пока не нужны, добавим позже точечно
- ❌ Contact Form 7, Fluent Forms — у нас своя форма заявок с трекингом
- ❌ Все плагины аналитики — GA/Я.Метрика подключаются через настройки темы

> **Важно про Yoast:** ты сам спросил про него. **НЕ ставь его.** Наша тема уже делает всё, что делает Yoast (sitemap, schema, og-теги, мета-описания). Yoast будет: (а) дублировать sitemap → Google запутается, (б) переопределять og-картинки → потеряем контроль, (в) кушать ресурсы хостинга. Если очень хочется — можно поставить **только** для редактирования meta title/description вручную, но это лишнее.

### 1.3. Чистка БД (опционально, но желательно)

Если на сайте уже есть мусор от старой темы:

```sql
-- Через phpMyAdmin → SQL
DELETE FROM wp_posts WHERE post_status = 'auto-draft' OR post_status = 'trash';
DELETE FROM wp_postmeta WHERE post_id NOT IN (SELECT ID FROM wp_posts);
DELETE FROM wp_options WHERE option_name LIKE '%transient%';
```

Или через плагин `WP-Optimize` (поставь, прогони, удали).

### 1.4. Проверка хостинга

Зайди в панель хостинга и убедись:
- **PHP версия:** 8.0 или выше (если 7.x — переключи в настройках хостинга)
- **MySQL:** 5.7+ или MariaDB 10.3+
- **Лимит памяти PHP:** 256M (если меньше — попроси саппорт хостинга поднять)
- **`max_execution_time`:** 60 секунд минимум
- **`upload_max_filesize`:** 32M минимум
- **Расширения PHP:** `gd` (для OG-картинок), `curl`, `mbstring`, `json`, `xml`

> Если хостинг — **shared** (общий) и у тебя сейчас тариф за 100₽/мес — переходи минимум на 300–500₽/мес тариф. На дешёвых тарифах WP+50 МФО+ ACF будет тормозить. Рекомендую: **Beget L**, **Timeweb Optimo**, **Sprinthost Эконом+**.

## ЧАСТЬ 2 — Установка темы и плагинов <a id="часть-2"></a>

### Порядок строго такой:

### Шаг 1. Установи ACF Pro

ACF Pro **обязателен** — без него карточки МФО не будут редактироваться.

1. Купи лицензию: https://www.advancedcustomfields.com/pro/ (~$49/год, разовый платёж — обновления год)
2. В личном кабинете ACF скачай `advanced-custom-fields-pro.zip`
3. WP-админка → Плагины → Добавить новый → **Загрузить плагин** → выбери zip → Установить → Активировать
4. Настройки → ACF → введи лицензионный ключ (из ЛК)

### Шаг 2. Установи нашу тему

1. Скачай `zaymi-online.zip` из этого репозитория (папка `thema/`)
2. WP-админка → Внешний вид → Темы → **Добавить новую** → **Загрузить тему**
3. Выбери `zaymi-online.zip` → Установить → **Активировать**

### Шаг 3. Подожди 30 секунд

После активации тема **сама** создаст:
- 50 МФО с условиями
- Все справочники (города, суммы, подборки)
- Юридические страницы
- Меню, виджеты, категории блога
- Настроит permalinks, часовой пояс, удалит "Hello World"

В верхней части админки появится **жёлтый баннер с чек-листом**, что осталось донастроить вручную (см. Часть 4).

### Шаг 4. Сбрось permalinks (страховка)

**Настройки → Постоянные ссылки → Сохранить** (без изменений).
Это активирует URL для `/go/`, `/sitemap.xml`, программатик-страниц.

### Шаг 5. Проверь что всё работает

Открой эти URL в браузере (замени `yoursite.ru` на свой):
- `https://yoursite.ru/` — должна открыться главная с каталогом МФО
- `https://yoursite.ru/mfo/lime-zaim/` — карточка МФО
- `https://yoursite.ru/zaymy/10000-rubley-na-30-dney/` — программатик-страница
- `https://yoursite.ru/sitemap.xml` — XML-карта
- `https://yoursite.ru/robots.txt` — должен содержать `Disallow: /go/`

Если что-то 404 — вернись к **Шагу 4** (сброс permalinks).

## ЧАСТЬ 4 — Ручные донастройки (~30 минут) <a id="часть-4"></a>

Открой **Внешний вид → Настройки темы Zaymi** и пройди по вкладкам:

### 4.1. Вкладка "Контакты"
- [ ] Телефон
- [ ] Email
- [ ] Юр. лицо / ИП (для дисклеймера)
- [ ] ОГРН/ИНН (для футера)

### 4.2. Вкладка "Интеграции и SEO"

#### 🔔 Telegram (5 минут, бесплатно)
**Зачем:** все заявки прилетают тебе в личку/канал в реалтайме.

1. Открой Telegram → найди `@BotFather` → отправь `/newbot`
2. Придумай имя (любое) → получи **токен** вида `7234567890:AAH...`
3. Вставь токен в поле **Telegram bot token**
4. Создай канал или группу → добавь своего бота админом
5. Открой в браузере: `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   (предварительно напиши боту любое сообщение, чтобы появился chat_id)
6. Найди в JSON `"chat":{"id":-1001234567890,...}` → скопируй число
7. Вставь в поле **Telegram chat_id**
8. Сохрани → нажми "Тестовая заявка" → должно прилететь сообщение

#### 🛡️ reCAPTCHA v3 (5 минут, бесплатно)
**Зачем:** защита формы от ботов (без капчи для юзера, всё на фоне).

1. Зайди https://www.google.com/recaptcha/admin
2. Создай новый сайт → тип **reCAPTCHA v3** → добавь домен
3. Получи **Site Key** и **Secret Key**
4. Вставь оба в настройки темы

#### 📊 Google Analytics + Яндекс.Метрика
1. Я.Метрика: https://metrika.yandex.ru/ → создай счётчик → скопируй **ID** (8 цифр) → вставь в настройки темы
2. GA4: https://analytics.google.com/ → создай поток → скопируй `G-XXXXXXX` → вставь в настройки темы
3. **Включи в Метрике:** Карта кликов, Вебвизор, Цели (заявка/клик по МФО — настроим позже)

#### 🚀 IndexNow (быстрая индексация в Bing/Yandex)
1. Зайди https://www.bing.com/indexnow
2. Сгенерируй ключ (32 hex символа) → сохрани
3. Вставь в поле **IndexNow ключ**
4. Подтверждающий файл `https://yoursite.ru/{ключ}.txt` отдаётся темой автоматически

#### 🔍 Yandex Webmaster API (опционально, ускоряет индексацию)
1. Подтверди сайт в https://webmaster.yandex.ru/
2. Создай OAuth-приложение: https://oauth.yandex.ru/client/new
3. Получи токен и Host ID → вставь в настройки темы

## ЧАСТЬ 5 — Подключение партнёрок МФО <a id="часть-5"></a>

**Это твой источник дохода.** Без этого сайт = красивая визитка.

### 5.1. Регистрация в CPA-сетях

Зарегистрируйся минимум в 3–4 (так получишь больше офферов и сравнишь выплаты):

| Сеть | Спец на МФО? | Плюсы |
|---|---|---|
| **Leads.su** | ⭐ Да, топ | Самый широкий выбор МФО, выплата от 1500₽/лид |
| **Salid** | ⭐ Да | Хорошие тарифы, быстрая выплата |
| **Mitgo (ex-Admitad)** | Частично | Для нефинанса тоже норм |
| **Profitner** | ⭐ Да | Эксклюзивные офферы |
| **LeadsTech** | Да | Подходит для холодного трафика |
| **EvaDav** | Нет, push | Для пушей и попандеров (опционально) |

**Как регистрироваться:**
1. Заходишь, заполняешь анкету: укажи **сайт** (твой домен), источник трафика — **SEO + контекст**, тематика — **финансы/займы**
2. Жди модерацию 1–3 дня
3. После одобрения — выбирай офферы МФО → копируй партнёрские ссылки

### 5.2. Привязка партнёрок к карточкам МФО

Для каждого МФО в админке:

1. **МФО → выбери карточку** (например "Лайм-займ")
2. Прокрути до блока **"Партнёрские настройки МФО"**
3. **Партнёрская ссылка** — вставь URL из CPA-сети с плейсхолдерами:
   ```
   https://leads.su/?aff=12345&offer=67&subid={clickid}&utm={utm_source}
   ```
   - `{clickid}` — наш ID клика (для постбэков и сверки)
   - `{utm_source}` — пробросится из URL посетителя
4. **Выплата за лид (₽)** — введи сколько платит CPA (для подсчёта EPC)
5. **% апрува** — средний апрув (узнай у менеджера CPA-сети)
6. Обнови.

После этого все кнопки "Получить" на сайте ведут на `/go/lime-zaim/` → редирект на партнёрку с трекингом.

> **ВАЖНО:** поля "Выплата за лид" и "% апрува" видны **только тебе в админке**, для подсчёта EPC. На сайте они не светятся.

### 5.3. Постбэки (сверка с CPA)

В CPA-сети найди раздел "Постбэки" → укажи URL:
```
https://yoursite.ru/wp-json/zaymi/v1/postback?clickid={subid}&status={status}&payout={payout}
```
Это позволит видеть в админке (Заявки → Клики) реальный EPC и одобрения.

## ЧАСТЬ 6 — SEO-настройка <a id="часть-6"></a>

### 6.1. Yoast НЕ нужен — повторяю

Тема уже делает:
- Title-теги (через `wp_title` фильтр)
- Meta description (из ACF поля или первого абзаца)
- Open Graph + Twitter Cards
- Schema.org (Organization, FinancialProduct, FAQ, Review, Breadcrumb)
- XML Sitemap
- robots.txt
- Canonical
- Hreflang (если нужно — пока не нужно, мы в RU)

**Если очень хочется** редактировать title/description **вручную для конкретной страницы** — поставь только **Yoast SEO Free** и **отключи в нём:**
- XML Sitemap (Settings → Features → XML sitemaps → OFF)
- Schema (Settings → Site features → Schema → OFF)
- Open Graph (Social → Facebook → OFF)
- Robots.txt (Tools → File editor — не трогай)

Останется только редактор meta-полей. Но честно — лишнее.

### 6.2. Подключение к поисковикам

#### Google Search Console
1. https://search.google.com/search-console → Добавить ресурс → **Доменный** (рекомендую) или **URL-префикс**
2. Подтверди через DNS (TXT-запись в панели регистратора домена)
3. Sitemaps → добавь `https://yoursite.ru/sitemap.xml`

#### Яндекс Вебмастер
1. https://webmaster.yandex.ru/ → Добавить сайт
2. Подтверди через мета-тег (вставь в настройки темы → "HTML в `<head>`") или DNS
3. Индексирование → Файлы Sitemap → `https://yoursite.ru/sitemap.xml`
4. Турбо-страницы → RSS-источники → `https://yoursite.ru/turbo.xml`
5. Региональность → выбери "Россия" (если работаешь по всей РФ) или конкретный город

### 6.3. Базовое семантическое ядро

Уже встроено через программатик-страницы (1000+ комбинаций сумма+срок+город+ситуация). Дополнительно собирай:

**Бесплатные инструменты:**
- **Wordstat Яндекса** — `https://wordstat.yandex.ru/` — введи "займ" и копируй все хвосты с частотностью >100
- **Google Trends** — для проверки сезонности
- **Bukvarix** (бесплатная версия 300 запросов в день)

**Платные (если бюджет есть):**
- **Key Collector** (~2000₽ единоразово)
- **Serpstat** или **Ahrefs** (от $99/мес — оправдано после первых 50к/мес дохода)

## ЧАСТЬ 7 — Контент-план на 90 дней <a id="часть-7"></a>

### Стратегия: **2 информационных + 1 коммерческая статья в неделю**

Информационные → ловят поисковый трафик через "как", "почему", "что делать"
Коммерческие → конверсионные сравнения и подборки → дают деньги

## ЧАСТЬ 8 — Как писать статьи <a id="часть-8"></a>

### 8.1. Структура статьи (всегда одинаковая)

```markdown
# H1: [Запрос максимально близко к Wordstat]

[Лид-абзац: 2–3 предложения, отвечающих на главный вопрос]

## Содержание (автогенерится темой)

## H2: Что такое [тема]
[200–300 слов, простыми словами]

## H2: Как это работает / Пошагово
[Список с шагами]

## H2: Когда подходит / Кому
[Списки маркированные]

## H2: ТОП-5 МФО для этой задачи
[Шорткод [zaymi_mfo_catalog limit=5 situation="..."]]

## H2: Частые ошибки
[3–5 пунктов]

## H2: FAQ (5–7 вопросов)
[Шорткод [zaymi_faq] или вручную в аккордеон]

## CTA в конце:
[Шорткод [zaymi_lead_form title="Подобрать займ"]]
```

### 8.2. Промпт для ChatGPT/Claude (копируй и используй)

```
Ты — финансовый редактор сайта о микрозаймах. Напиши статью на тему: "[ТЕМА]".

Требования:
- Объём: 1500–2500 слов
- Стиль: дружелюбный, простой, без канцелярита, как объясняешь другу
- Структура: H1, лид, 5–7 H2 разделов, FAQ из 5 вопросов
- Целевой запрос: "[КЛЮЧ]" — встрой в H1, первый абзац и 2–3 раза по тексту естественно
- LSI-слова: займ, МФО, микрокредит, одобрение, КИ, ставка, переплата
- В конце — таблица сравнения 3 МФО (бери из списка: Lime, Zaymer, MoneyMan, Webbankir, Kviku)
- Юридическая корректность: НЕ обещай 100% одобрение, упоминай что решение за МФО
- E-E-A-T: добавь блок "Мнение эксперта" с 2–3 фактами
- Тон: экспертный, но человечный

В конце выдай:
1. SEO title (до 60 символов)
2. Meta description (до 155 символов)
3. 5 LSI-запросов для перелинковки
```

### 8.3. Процесс публикации (15 минут на статью)

1. Сгенерь черновик через ИИ (промпт выше)
2. **Прочитай и поправь** факты, цифры, ставки (ИИ галлюцинирует — особенно про %)
3. Записи → Добавить новую → вставь
4. Поставь категорию (Гайды / Сравнения / Новости)
5. Загрузи обложку (бери с unsplash.com или генерь в Midjourney/DALL-E)
6. В конце добавь шорткоды:
   ```
   [zaymi_mfo_catalog limit=5]
   [zaymi_lead_form title="Получить займ за 5 минут"]
   [zaymi_related_mfo]
   ```
7. Проверь preview → Опубликовать

### 8.4. Что НЕ делать в статьях

- ❌ Не копируй с других сайтов (Яндекс/Google это видят за секунды)
- ❌ Не обещай "100% одобрение", "без проверки КИ", "всем без отказа" — попадёшь под санкции ЦБ за рекламу финуслуг
- ❌ Не выдумывай ставки — бери реальные с сайтов МФО
- ❌ Не вставляй >3 ключей подряд — это переспам

## ЧАСТЬ 9 — Платный трафик <a id="часть-9"></a>

### Когда подключать?
- **Сразу после установки** — если есть бюджет 10–30к₽/мес для теста
- **После 50–100 заявок с SEO** — когда увидел какие МФО конвертят лучше

### 9.1. Яндекс.Директ (главный источник)

**Стратегия для МФО:**

1. **РСЯ кампании** (картинки + текст в сетях Яндекса) — самый дешёвый трафик
   - Запросы типа: "займ онлайн", "взять микрозайм", "займ на карту срочно"
   - Бюджет на тест: 5000₽/неделя на одну кампанию
   - Ставка: автостратегия "Оплата за конверсии" → цель = "лид"

2. **Поиск** — дороже, но горячий трафик
   - Только узкие коммерческие: "lime займ оформить", "займер вход"
   - Минус-слова обязательно: "отзывы", "развод", "обман", "не платить", "коллекторы"

**Связка с темой:**
- Создай отдельные посадочные через программатик: `/zaymy/10000-rubley-na-30-dney/?utm_source=yandex&utm_campaign=10k-30d`
- В настройках темы включи цели в Я.Метрике:
  - `lead_submit` — отправка формы
  - `mfo_click` — клик по кнопке "Получить"

> **Закон о рекламе финуслуг:** в объявлениях ОБЯЗАТЕЛЬНО указывать ПСК (полная стоимость кредита). Шаблон: "Займы от 0% до 365% годовых. Сумма от 1000 до 100000₽."

### 9.2. Telegram Ads / посевы в каналах

- **Посевы** — пиши админам каналов о финансах/лайфхаках/деньгах, заказывай рекламу. От 500–5000₽ за пост в зависимости от охвата.
- **Telegram Ads** (официальная) — от €2 CPM, нужен бюджет от €1500 на старт. Пока пропускай.

### 9.3. SEO-крауд (форумы, отзовики)

Бесплатно и долго работает:
- Banki.ru — отвечай на вопросы людей про займы → ставь ссылку на свой гайд
- Otzovik, irecommend — отзывы на МФО со ссылкой
- Pikabu, VC.ru — гостевые статьи

## ЧАСТЬ 10 — Аналитика и оптимизация <a id="часть-10"></a>

### Что смотреть КАЖДЫЙ ДЕНЬ (5 минут):

1. **Заявки в админке** — сколько за вчера
2. **Клики по МФО (CR/EPC)** — какие МФО приносят деньги, какие нет
3. **Telegram-канал** — заявки в реалтайме

### Что смотреть КАЖДУЮ НЕДЕЛЮ (30 минут):

1. **Я.Метрика → Источники** — откуда трафик (SEO/Директ/прямой)
2. **Я.Метрика → Карта кликов** — что юзеры жмут на главной
3. **Я.Метрика → Вебвизор** — посмотри 5 случайных сессий, найди где люди уходят
4. **Search Console / Я.Вебмастер** — какие запросы в ТОП-10, что подросло
5. **CR по МФО** — отключи МФО с CR <2% или EPC <50₽

### Ключевые метрики (KPI):

| Метрика | Цель |
|---|---|
| CR (заявка / клик по МФО) | >5% |
| EPC (доход / клик по МФО) | >100₽ |
| % одобрений (от CPA) | >20% |
| Доход на 1000 посетителей (RPM) | >300₽ |

## ЧАСТЬ 11 — Автоматизация <a id="часть-11"></a>

### 11.1. Автопостинг через ИИ (когда выйдешь на 50+ статей)

**Make.com (бывший Integromat) сценарий:**
1. Триггер: каждый понедельник 10:00
2. ChatGPT API → сгенерируй статью по шаблону
3. WordPress REST API → создай черновик
4. Telegram → отправь тебе ссылку на черновик для модерации

Бюджет: ~$10/мес OpenAI + $9/мес Make.

### 11.2. Автообновление условий МФО

Раз в месяц вручную проверяй ставки на сайтах МФО (не более 2 часов на 50 МФО). Или закажи парсер у фрилансера на Kwork (~3000₽).

### 11.3. Автоответы на отзывы

В админке Заявки → Отзывы — модерируй раз в неделю. На негативные отвечай шаблоном: "Спасибо за отзыв. Передали в МФО. Если ситуация требует решения — напишите нам на [email]".

### 11.4. Бэкапы

UpdraftPlus → Настройки → Расписание:
- БД: ежедневно
- Файлы: раз в неделю
- Хранение: Google Drive или Dropbox (бесплатно)

## ЧАСТЬ 13 — Частые ошибки и FAQ <a id="часть-13"></a>

**Q: Залил тему, но нет МФО / страниц.**
A: Активируй ещё раз (Внешний вид → Темы → переключись на дефолт и обратно). Либо МФО → Tools → Запустить сидер.

**Q: 404 на `/sitemap.xml` или `/go/`.**
A: Настройки → Постоянные ссылки → Сохранить.

**Q: Yoast тоже отдаёт sitemap, какой использовать?**
A: Удали Yoast (см. часть 1). Если нужен — отключи в нём sitemap.

**Q: Заявки не приходят в Telegram.**
A: Проверь токен и chat_id. Бот должен быть админом канала. Тест: в настройках темы кнопка "Тестовая заявка".

**Q: Logи МФО — белые квадраты.**
A: МФО → Tools → Перегенерировать плейсхолдеры. Или загрузи реальные через "Изображение записи".

**Q: Сайт медленный.**
A: Поставь **LiteSpeed Cache** (если хостинг на LiteSpeed) или **WP Rocket** (платный, $59/год). Включи: Page Cache, Lazy Load, Minify CSS/JS.

**Q: Сколько денег вложить на старте?**
A: Минимум: ACF Pro $49 + хостинг ~5000₽/год + домен 200₽/год = ~10к₽. Опционально: 30к₽ на тест Я.Директ.

**Q: Можно ли без ИИ писать статьи?**
A: Можно, но 2 статьи/неделя руками = 8–10 часов твоего времени. ИИ + редактура = 1.5 часа/статья. Считай.

**Q: Когда первый доход?**
A: Реалистично: первый рубль — на 2–3 неделе (с Директа). Стабильные 30к/мес — 6–8 недель. 200к+ — 4–6 месяцев плотной работы.

**Q: Какой домен выбрать?**
A: Если ещё не купил: `zaim-podbor.ru`, `mfo-online24.ru` — что-то с ключом, .ru обязательно.

**Q: Можно ли клонировать сайт на 2-й домен?**
A: Можно, но Яндекс посчитает аффилиатами и оба попадут под фильтр. Делай разные ниши: один — займы, второй — кредитные карты.
