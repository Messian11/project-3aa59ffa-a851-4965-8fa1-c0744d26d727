## Установка

1. Установить **ACF Pro** (платный, обязательно).
2. Загрузить эту тему: `Внешний вид → Темы → Добавить → Загрузить тему → zaymi-online-base.zip → Установить → Активировать`.
3. При активации сидер автоматически создаст весь демо-контент. Проверь: `МФО → Все МФО` — должно быть 8 записей с логотипами.
4. Проверь поля: открой любую МФО → справа блоки «Карточка», «Плюсы/минусы», «Шаги», «Тарифы», «FAQ», «SEO».
5. Перейди в `МФО → Инструменты` — там список всех шорткодов.

```
├── screenshot.png
├── functions.php            ← главный загрузчик
├── inc/
│   ├── setup.php            ← theme support, меню
│   ├── enqueue.php          ← подключение CSS/JS/шрифтов
│   ├── cpt.php              ← регистрация mfo + таксономий

│   ├── seeder.php           ← автозасев демо-контента
│   └── admin.php            ← страница «Инструменты»
├── assets/
│   ├── css/main.css         ← скомпилированный Tailwind (125 КБ)
│   ├── css/extra.css        ← оверрайды
│   ├── js/app.js            ← мобильное меню, скролл
│   └── images/mfo/*.png     ← 8 логотипов МФО (плейсхолдеры)

    ├── cities.json          ← 10 городов
    ├── situations.json      ← 6 подборок
    ├── amounts.json         ← 9 сумм
    └── articles.json        ← 3 статьи
```

## Замена логотипов

Плейсхолдеры (цветной квадрат с названием) лежат в `assets/images/mfo/`.  
После активации они уже импортированы в медиабиблиотеку.  
Чтобы поменять: `МФО → Займер → блок «Карточка» → Логотип → Удалить → Загрузить новый → Обновить`.

## Шорткоды (доступны после v1.1)

Полный список — в админке: `МФО → Инструменты`.
