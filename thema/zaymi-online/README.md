# Zaymi Online — WordPress тема (v2.0 — Conversion + SEO)

Полноценная тема для портала по подбору МФО с автозасевом контента, конверсионными виджетами, программатик-SEO и интеграциями с CRM.

## Установка — пошаговая инструкция (без знания кода)

### Шаг 1. Подготовь хостинг WordPress
Любой обычный хостинг с WordPress 6.x, PHP 8.0+, MySQL 5.7+ (Beget, Timeweb, Reg.ru, Sprinthost — подойдут).

### Шаг 2. Установи плагин ACF Pro
Без него поля МФО, тарифы и FAQ работать не будут.
- Купи ACF Pro: https://www.advancedcustomfields.com/pro/ (~$49/год)
- Скачай плагин из личного кабинета
- В админке WordPress: **Плагины → Добавить новый → Загрузить плагин** → выбери `acf-pro.zip` → активируй
- Введи лицензионный ключ в **Настройки → ACF**

### Шаг 3. Залей тему
Два способа:

**Через админку (проще):**
1. **Внешний вид → Темы → Добавить новую → Загрузить тему**
2. Выбери `zaymi-online.zip` из этого репозитория
3. Нажми **Установить → Активировать**

**Через FTP/файловый менеджер:**
1. Распакуй `zaymi-online.zip`
2. Загрузи папку `zaymi-online` в `/wp-content/themes/`
3. В админке: **Внешний вид → Темы → Активировать**

### Шаг 4. Дождись автозасева (10–30 сек)
Тема при первой активации автоматически создаст:
- 50 МФО с плейсхолдер-логотипами
- 10 городов, 6 подборок, 9 сумм, 3 статьи блога
- 4 страницы (Главная, О нас, Контакты, Политика)

Если не сработало — иди в **МФО → Tools → Запустить сидер**.

### Шаг 5. Сбрось постоянные ссылки (ВАЖНО!)
**Настройки → Постоянные ссылки → Сохранить** (без изменений). Это активирует URL-правила для `/go/`, `/sitemap.xml`, `/zaymy/...`.

### Шаг 6. Настрой интеграции
Открой **Внешний вид → Настройки темы Zaymi → вкладка «Интеграции и SEO»**.

#### 6.1. Telegram (бесплатно, 5 минут)
1. В Telegram найди `@BotFather` → `/newbot` → придумай имя → получи **токен**
2. Вставь токен в поле **Telegram bot token**
3. Создай канал/группу, добавь бота админом
4. Открой `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates` → найди `chat_id`
5. Вставь `chat_id` в поле **Telegram chat_id**

После каждой заявки в Telegram прилетит уведомление.

#### 6.2. Bitrix24 (опционально)
1. В Bitrix24: **Приложения → Разработчикам → Другое → Входящий вебхук**
2. Скопируй URL вида `https://your.bitrix24.ru/rest/1/xxxxx/`
3. Вставь в поле **Bitrix24 webhook URL**

#### 6.3. AmoCRM (опционально)
1. В AmoCRM: **Настройки → Интеграции → Webhooks → Добавить**
2. Скопируй URL → вставь в поле **AmoCRM webhook URL**

#### 6.4. IndexNow (быстрая индексация в Bing/Yandex)
1. Сгенерируй ключ на https://www.bing.com/indexnow/ (32 hex символа)
2. Вставь в поле **IndexNow ключ**
3. Файл подтверждения отдаётся автоматически по `https://yoursite.ru/{key}.txt`

#### 6.5. Yandex Webmaster API (быстрая переиндексация в Яндексе)
1. Зайди в Яндекс Вебмастер → подтверди сайт
2. Получи OAuth token: https://oauth.yandex.ru/authorize?response_type=token&client_id=XXX (нужно создать приложение)
3. Узнай Host ID через `https://api.webmaster.yandex.net/v4/user/{user_id}/hosts`
4. Вставь оба значения в настройки

#### 6.6. Google Analytics + Яндекс.Метрика
Просто введи `G-XXXXXXX` и ID счётчика — скрипты подключатся автоматически.

### Шаг 7. Настрой партнёрские ссылки МФО
1. **МФО → выбери карточку → секция «Партнёрские настройки МФО»**
2. **Партнёрская ссылка** — сюда вставь URL из партнёрки (Leads.su, Salid, Mitgo, Profitner)
3. Можешь использовать плейсхолдеры:
   - `{clickid}` — наш ID клика (для постбэков)
   - `{utm_source}`, `{utm_campaign}` — пробрасываются из URL посетителя

Пример: `https://leads.su/?aff=12345&offer=67&subid={clickid}&utm={utm_source}`

Теперь все кнопки «Получить» ведут на `/go/lime-zaim/` → редирект на партнёрку с трекингом.

### Шаг 8. Подключи sitemap к поисковикам
- **Google Search Console** → Sitemap → добавь `https://yoursite.ru/sitemap.xml`
- **Яндекс Вебмастер** → Индексирование → Файлы Sitemap → добавь то же
- **Турбо-страницы** в Я.Вебмастере → RSS-источники → `https://yoursite.ru/turbo.xml`

### Шаг 9. (Опционально) Загрузи реальные логотипы МФО
1. **МФО → выбери карточку → Изображение записи** → загрузи логотип
2. Плейсхолдер заменится на реальный

## Управление контентом из админки (без HTML)

- **Новое МФО**: МФО → Добавить новое → заполни ACF поля → Опубликовать
- **Новая статья**: Записи → Добавить новую → Опубликовать
- **Новый город**: МФО → Города → Добавить новый
- **Изменить логотип МФО**: МФО → редактировать → Изображение записи
- **Изменить ставки/условия**: МФО → редактировать → блок ACF полей справа
- **Изменить FAQ на странице МФО**: блок «FAQ» внизу редактора
- **Изменить тексты на главной**: Страницы → Главная → отредактируй шорткоды

## Где смотреть статистику

- **Заявки**: левое меню → **Заявки** (200 последних, кнопка экспорта CSV)
- **Клики по партнёркам**: **Заявки → Клики (CR/EPC)**
- **CR (конверсия)** считается автоматически: заявки / клики × 100%

---

## Бэкап и обновление

- Тема не трогает существующие записи и страницы повторно (сидер идемпотентный)
- Перед обновлением темы сделай бэкап БД (плагин WPvivid или UpdraftPlus)
- Все настройки хранятся в `wp_options` (ACF) — переживут переустановку темы

---

## Что точно НЕ нужно делать

- ❌ Редактировать файлы темы напрямую через FTP — потеряешь при обновлении
- ❌ Использовать визуальные конструкторы (Elementor) — сломают шорткоды
- ❌ Удалять плагин ACF Pro — поля исчезнут

## Поддержка

Если что-то не работает после установки:
1. **Постоянные ссылки** не сброшены → Настройки → Постоянные ссылки → Сохранить
2. **ACF Pro не активирован** → красный баннер сверху админки
3. **GD не установлен** на хостинге → OG-картинки не сгенерируются (попроси хостера установить `php-gd`)
4. **Логотипы белые квадраты** → запусти сидер ещё раз: МФО → Tools
