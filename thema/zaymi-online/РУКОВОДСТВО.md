## 1. ⚙️ УСТАНОВКА ТЕМЫ (5 минут)

### Способ 1 — через wp-admin (рекомендуется)

1. Войдите в `https://ваш-сайт.ru/wp-admin/`
2. **Внешний вид → Темы → Добавить новую → Загрузить тему**
3. Выберите файл `zaymi-online-FINAL.zip` → **Установить → Активировать**
4. Сразу зайдите в **Настройки → Постоянные ссылки** → выберите «Название записи» → **Сохранить**
5. Откройте главную сайта — должна работать.

### Способ 2 — через FTP/файловый менеджер хостинга

1. Распакуйте `zaymi-online-FINAL.zip`
2. Загрузите папку `zaymi-online/` в `/wp-content/themes/`
3. В админке: **Внешний вид → Темы → Активировать «Zaymi Online»**
4. **Настройки → Постоянные ссылки → Сохранить**

### Что произойдёт автоматически после активации:

- ✅ Создадутся типы записей: МФО, Подборки, Города, Суммы
- ✅ Засеется демо-контент: 8 МФО, 10 городов, 6 подборок, 9 сумм, 3 статьи
- ✅ Создадутся юридические страницы (Политика, Согласие, Контакты, О нас)
- ✅ Включатся ЧПУ
- ✅ Подгрузится шрифт Inter, Tailwind CSS, иконки

## 3. 📅 ПЛАН НА ПЕРВЫЕ 30 ДНЕЙ

### 🟢 ДЕНЬ 1 — Базовая настройка (2 часа)

- [ ] Установить тему (см. раздел 1)
- [ ] **Настройки → Общие** — название сайта, описание, часовой пояс «Москва»
- [ ] **Настройки → Постоянные ссылки** → «Название записи» → Сохранить
- [ ] **Внешний вид → Меню** — меню «Главное меню» уже создано автоматически. Привязать к области «Главное меню» если ещё не привязано.
- [ ] **Zaymi → Настройки** — заполнить:
  - Название агрегатора, телефон, email
  - Текст в подвале (дисклеймер)
  - Имя и URL для CTA в шапке
- [ ] **Внешний вид → Настроить → Иконка сайта** — загрузить favicon (192×192)

### 🟢 ДЕНЬ 2 — Подключить аналитику (1 час)

- [ ] Зарегистрироваться в **Яндекс.Метрика** → создать счётчик → скопировать код
- [ ] Зарегистрироваться в **Google Analytics 4** → получить Measurement ID
- [ ] Установить плагин **Site Kit by Google** (для GA4) или вставить коды через **Zaymi → Настройки → Аналитика**
- [ ] Подтвердить домен в **Яндекс.Вебмастер** и **Google Search Console**
- [ ] Загрузить sitemap.xml в обоих сервисах: `https://ваш-сайт.ru/sitemap.xml`

### 🟢 ДЕНЬ 3-4 — Заполнить контент МФО (4-6 часов)

Демо-контент уже есть, но желательно его дополнить реальными данными:

1. **Записи → МФО → Все МФО** — открыть каждую карточку
2. Заполнить поля ACF справа:
   - Логотип МФО
   - Минимальная и максимальная сумма
   - Минимальный и максимальный срок
   - Ставка от/до
   - Процент одобрения
   - Партнёрская ссылка (CPA)
   - Бейджи (Без отказа, С плохой КИ и т.д.)
   - Условия (плюсы/минусы, шаги получения)
3. Добавить новые МФО: **МФО → Добавить новое**
4. Привязать МФО к подборкам (Без отказа, Без справок и т.д.) — таксономия «Подборки» в правом сайдбаре

### 🟢 ДЕНЬ 5 — AI-Writer для статей (1 час настройка)

См. подробно [раздел 5](#ai-генерация). Кратко:

1. Получить API-ключ нейронки (рекомендую DeepSeek — дёшево и качественно для русского языка)
2. **Zaymi → AI Writer → Настройки** — вставить ключ
3. Сгенерировать первые 5 статей через **AI Writer → Создать**
4. Опубликовать после ручной редактуры

### 🟢 ДЕНЬ 6-7 — Настроить лидогенерацию (2 часа)

- [ ] **Zaymi → Лиды** — здесь будут все заявки
- [ ] **Zaymi → Настройки → Telegram** — подключить бота для уведомлений (опционально, см. ниже)
- [ ] Установить reCAPTCHA v3 от Google для защиты форм
- [ ] Проверить отправку формы тестовой заявкой

### 🟡 НЕДЕЛЯ 2 — Контент-стратегия

- [ ] Запустить AI-генерацию по 5 статей в день (всего ~35 за неделю)
- [ ] Темы статей: «Как взять займ», «Что такое МФО», «Лучшие МФО 2026», обзоры конкретных МФО
- [ ] Каждую статью **обязательно вычитать** перед публикацией — нейронки могут писать неточности про финансы
- [ ] Добавить внутренние ссылки между статьями
- [ ] Сделать **минимум одну фотографию/иллюстрацию** для каждой статьи

### 🟡 НЕДЕЛЯ 3 — SEO-оптимизация

- [ ] Установить плагин **Yoast SEO** или **Rank Math** для удобной работы с meta
- [ ] Прописать уникальные title/description для топ-10 страниц
- [ ] Сделать перелинковку: с каждой подборки — ссылки на 3-5 МФО, и обратно
- [ ] Заказать первые ссылки (крауд-маркетинг, гостевые посты)
- [ ] Зарегистрироваться в **финансовых каталогах**: banki.ru, sravni.ru, vbr.ru

### 🔵 НЕДЕЛЯ 4 — Монетизация

- [ ] Подключить **CPA-сети**: Leads.su, Salid, Indoleads, ActionPay

```
   ├─ Виджеты (футер)
   └─ Темы
🔌 Плагины

```

### Где что лежит:

**Изменить главную страницу:**
Главная собирается из шорткодов в `front-page.php`. Чтобы изменить блоки — отредактируйте файл темы. Если нужно делать главную через визуальный конструктор — создайте обычную «Страницу» с шорткодами и установите её главной в **Настройки → Чтение**.

**Добавить новую подборку:**
**Подборки → Добавить новую**. Заполните slug (латиницей, например `dlya-vodit`), название («Водителям») и (опционально) описание. Шаблон сразу будет красивым.

**Добавить новый город:**
**Города → Добавить новый**. Slug — латиницей (`omsk`), название — кириллицей.

**Изменить шапку/подвал:**
Файлы темы: `header.php` и `footer.php`. Подменить тексты можно через **Zaymi → Настройки**.

## 5. 🤖 AI-ГЕНЕРАЦИЯ КОНТЕНТА (НЕЙРОНКИ)

В теме встроен модуль **AI Writer**, который умеет генерировать статьи через любого из 6 провайдеров. Работает по слотам: ставите тему/ключевик → получаете готовую статью с H1/H2/H3, картинками-плейсхолдерами и meta-данными.

### 5.1 Сравнение нейронок

| Провайдер | Цена за 1000 статей* | Качество русского | API в РФ | Рекомендация |
|-----------|---------------------|-------------------|---------|--------------|
| **DeepSeek** | ~$5 (~500₽) | ⭐⭐⭐⭐ | ✅ работает напрямую | 🥇 **Лучший выбор** |
| **YandexGPT 4 Pro** | ~1500₽ | ⭐⭐⭐⭐⭐ | ✅ работает | 🥈 для важных статей |
| **GigaChat (Сбер)** | бесплатно (есть лимиты) | ⭐⭐⭐⭐ | ✅ работает | 🥉 на старт |
| **Google Gemini 2.5 Pro** | ~$3 (~300₽) | ⭐⭐⭐⭐ | ⚠️ нужен VPN на сервере | для массива |
| **OpenAI GPT-5 mini** | ~$15 (~1500₽) | ⭐⭐⭐⭐⭐ | ⚠️ нужен VPN | премиум |
| **Anthropic Claude Sonnet 4** | ~$30 (~3000₽) | ⭐⭐⭐⭐⭐ | ⚠️ нужен VPN | топ-качество |

\* Расчёт примерный для статьи ~3000 знаков. Цены меняются — сверяйтесь на сайтах провайдеров.

### 5.2 Как получить API-ключ

#### 🟢 DeepSeek (рекомендую)

1. Перейти https://platform.deepseek.com/
2. Зарегистрироваться через email или Google
3. Пополнить баланс на $5–10 (карта МИР работает)
4. Раздел **API Keys → Create new key** → скопировать
5. Вставить в **Zaymi → AI Writer → Настройки → DeepSeek API Key**
6. Выбрать модель: `deepseek-chat` (для статей) или `deepseek-reasoner` (для аналитики)

#### 🟢 GigaChat (Сбер) — бесплатный лимит

1. Перейти https://developers.sber.ru/portal/products/gigachat-api
2. Войти через Сбер ID
3. Создать «Сервис» → получить **Authorization Key** (длинный base64)
4. Вставить в **Zaymi → AI Writer → Настройки → GigaChat Authorization**
5. Лимит для физлиц: 1 млн токенов в месяц бесплатно (~300 статей)

#### 🟢 YandexGPT 4

1. Зайти в https://console.yandex.cloud/
2. Создать платёжный аккаунт (привязать карту)
3. Создать сервисный аккаунт с ролью `ai.languageModels.user`
4. Получить **API-ключ** для сервисного аккаунта
5. Скопировать **Folder ID** (id каталога)
6. Вставить ключ + Folder ID в **Zaymi → AI Writer → YandexGPT**
7. Выбрать модель: `yandexgpt/latest` (Pro) или `yandexgpt-lite/latest` (дёшево)

#### 🟡 OpenAI GPT-5

1. https://platform.openai.com/ → зарегистрироваться
2. Пополнить баланс ($5 минимум)
3. **API Keys → Create** → ключ начинается с `sk-...`
4. **Внимание:** API не работает с российских IP — нужен VPS за рубежом или VPN на сервере
5. Вставить в **Zaymi → AI Writer → OpenAI API Key**
6. Модель: `gpt-5-mini` (баланс цены и качества)

#### 🟡 Google Gemini

1. https://aistudio.google.com/app/apikey
2. Войти через Google → **Create API Key**
3. Также нужен зарубежный IP сервера
4. Вставить в **Zaymi → AI Writer → Gemini API Key**
5. Модель: `gemini-2.5-flash` (быстро и дёшево) или `gemini-2.5-pro` (топ)

#### 🟡 Anthropic Claude

1. https://console.anthropic.com/
2. Регистрация только с зарубежных номеров (можно через виртуальный)
3. Пополнение через карту иностранного банка
4. **API Keys → Create Key** (`sk-ant-...`)
5. Зарубежный IP обязателен
6. Модель: `claude-sonnet-4` (баланс) или `claude-opus-4` (премиум)

### 5.3 Как пользоваться AI Writer

1. **Zaymi → AI Writer → Создать статью**
2. Заполнить:
   - **Тема статьи:** «Как взять займ без отказа в 2026 году»
   - **Ключевые слова:** `займ без отказа, мфо без отказа, займы онлайн`
   - **Длина:** 3000-5000 знаков
   - **Стиль:** информационный / экспертный / разговорный
   - **Провайдер:** DeepSeek (или другой)
3. Нажать **«Сгенерировать»**
4. Через 30-60 секунд появится готовый черновик
5. **Обязательно прочитать и поправить** факты, цифры, проценты
6. Добавить картинку (через Медиафайлы)
7. Прописать SEO meta (через плагин Yoast/Rank Math)
8. **Опубликовать**

### 5.4 Массовая генерация по расписанию

В теме есть **Cron** для автогенерации:

1. **Zaymi → AI Writer → Cron**
2. Загрузить CSV со списком тем (1 строка = 1 тема)
3. Установить расписание: «1 статья каждые 6 часов» или «5 статей в сутки»
4. Включить «Автопубликация» (или оставить как черновики на ручную модерацию)

⚠️ **Важно:** Google и Яндекс умеют распознавать AI-контент. Чтобы статьи не понижали — обязательно:
- Добавляйте **личный опыт** (1-2 абзаца от себя)
- Вставляйте **уникальные цифры** (свежая статистика, скрины)
- Делайте **уникальные иллюстрации** (хотя бы через Canva/Figma)
- Привязывайте к **автору-эксперту** (см. раздел «Авторы» в админке)

- ✅ Адаптив + быстрая загрузка
- ✅ Lazy-load картинок

### 6.2 Контентный SEO

**Структура страниц:**
- 1 H1 на страницу (уже соблюдено)
- H2 для основных секций, H3 для подсекций
- Title 50-60 символов с ключом в начале
- Description 150-160 символов с CTA

**Ключевые слова — где брать:**
- **Wordstat** (https://wordstat.yandex.ru) — для русского сегмента
- **Букварикс** — бесплатная база ключей
- **Keys.so** — конкурентная разведка
- **Serpstat / Ahrefs** — платные, но мощные

**Семантическое ядро для МФО (стартовые ключи):**
```
займ онлайн на карту
мфо без отказа
займ с плохой кредитной историей
кредит на карту срочно
микрозайм быстро
лучшие мфо 2026
займ за 5 минут
кредит без справок
мфо для пенсионеров
```

### 6.3 Внешнее SEO (ссылки)

## 9. 🆘 РЕШЕНИЕ ПРОБЛЕМ

### Белый экран после активации темы

1. Зайти в файловый менеджер хостинга → `/wp-content/themes/`
2. Переименовать `zaymi-online` → `zaymi-online-off`
3. WordPress автоматически переключится на дефолтную тему
4. Зайти в админку → диагностика
5. Включить debug в `wp-config.php`:
   ```php
   define('WP_DEBUG', true);
   define('WP_DEBUG_LOG', true);
   define('WP_DEBUG_DISPLAY', false);
   ```
6. Логи появятся в `/wp-content/debug.log`

### Стили не загружаются (сайт без CSS)

1. **Настройки → Постоянные ссылки → Сохранить** (обновляет правила .htaccess)
2. Очистить кеш браузера: Ctrl+Shift+R
3. Если у вас есть кеширующий плагин (WP Rocket, W3 Total Cache) — очистить его кеш
4. Проверить в браузере (F12 → Network) подгружается ли `tailwind.min.css` со статусом 200

### 404 на страницах /mfo/, /situations/, /goroda/

**Настройки → Постоянные ссылки → Сохранить** (без изменений). Это перерегистрирует правила переадресации для CPT.

### AI Writer не генерирует статьи

1. Проверить API-ключ в **Zaymi → AI Writer → Настройки**
2. Проверить баланс на стороне провайдера (DeepSeek/OpenAI/...)
3. Для зарубежных API (OpenAI, Gemini, Claude) — настроить VPN на сервере или использовать VPS за границей
4. Открыть `/wp-content/debug.log` — посмотреть ошибки

### Лиды не приходят на email

1. Установить плагин **WP Mail SMTP** для отправки через Gmail/Yandex SMTP
2. Указать корректный SMTP-сервер вашего почтового провайдера
3. Тестовая отправка → должно прийти на ваш email
4. В **Zaymi → Настройки → Email для лидов** указать рабочий ящик

### Сайт медленно грузится

1. Установить плагин **WP Super Cache** или **WP Rocket**
2. Включить сжатие изображений: **Smush** или **ShortPixel**
3. Подключить CDN: **Cloudflare** (бесплатно)
4. Проверить скорость: https://pagespeed.web.dev/

## 🖼 Как сменить логотип за 30 секунд

В теме v2.1+ логотип меняется **3 кликами** без редактирования файлов:

### Вариант 1 — через дашборд (быстрее)
1. **Консоль** (главная админки) → виджет «🖼 Логотип Zaymi»
2. Кнопка **«Сменить логотип»**
3. Загрузите PNG/SVG (рекомендуется 320×80) → **«Опубликовать»**

### Вариант 2 — через Customizer
1. **Внешний вид → Настроить** → секция **«🖼 Логотип Zaymi»**
2. Также рядом откроется блок **«Свойства сайта»** → **Логотип** → загрузите файл
3. Можно отдельно загрузить **логотип для футера** (обычно белая версия)
4. Выставить **высоту в шапке** (по умолчанию 40px, диапазон 24–96)

### Вариант 3 — через меню МФО
**МФО → 🖼 Логотип сайта** — открывает Customizer сразу на нужной секции.

### Что происходит автоматически
- Логотип появляется в **шапке** на всех страницах
- В **футере** — либо отдельная версия (если загрузили), либо тот же логотип (с авто-инверсией под тёмный фон)
- В **OG-картинке** для соцсетей (если включён `inc/og-image.php`)
- В **Schema.org Organization** — для Яндекса и Google

### Фавикон (иконка вкладки)
**Внешний вид → Настроить → Свойства сайта → Иконка сайта** — рекомендуется квадрат 512×512 PNG.

### Если что-то пошло не так
- Очистите кэш браузера: **Ctrl+Shift+R**
- Если есть кэш-плагин (W3 Total Cache, WP Rocket) — сбросьте
- Логотип-фолбэк лежит в `wp-content/themes/zaymi-online/assets/img/logo.png` — можете заменить файлом напрямую, тогда он будет использоваться автоматически если в Customizer ничего не выбрано

## ⚡ Авто-импорт МФО из Leads.su (новое в v3.0)

Не нужно вручную создавать карточки МФО — тема сама подтянет ваши подключённые офферы из CPA-сети **Leads.su**.

### Шаг 1. Получите токен
1. Войдите в [webmaster.leads.su](https://webmaster.leads.su/account/default).
2. Раздел **Настройки → API** → скопируйте токен.
3. В разделе **Площадки** запомните `platform_id` вашей площадки (нужен для персональных партнёрских ссылок).

### Шаг 2. Подключите в WordPress
1. **МФО → ⚡ Импорт Leads.su**.
2. Вставьте токен и `platform_id`.
3. Поставьте галочку «Запускать ежедневно» — синк будет автоматический.
4. Кнопка **▶ Импортировать** — запуск прямо сейчас.

### Что происходит при синке
- Создаются/обновляются записи CPT `mfo`.
- Логотип оффера → миниатюра поста.
- Партнёрская ссылка → поле `mfo_partner_url` (используется во всех CTA).
- Тарифы (сумма/срок/ставка) подтягиваются, если их отдаёт API.
- Записи никогда не удаляются — повторный импорт только обновляет.

### Фильтр по категории
По умолчанию импортируются только офферы с категорией, содержащей `mikrofinansy` / `микрофин` / `займ`. Можно изменить в поле «Фильтр по категории» или оставить пустым (импортировать всё).

### Безопасность
- Новые МФО создаются в статусе **черновик** — вы их сначала проверяете, потом публикуете.
- Можно поставить галочку «Сразу публиковать», но рекомендуем первый раз пройти список руками.

## 🔗 Авто-перелинковка статей (новое в v3.0)

В каждой статье блога тема **автоматически** превращает в ссылки:
- Имена МФО → `/mfo/{slug}/`
- «займ в {Город}» → `/goroda/{slug}/`
- «займ 5000 рублей», «займ на 30000 рублей» → `/summa/{slug}/`
- Имена подборок (без отказа, пенсионерам и т.д.) → `/situations/{slug}/`

**Защита от переоптимизации:**
- Один и тот же ключ → не больше 1 раза в статье.
- Всего не более 8 авто-ссылок на статью.
- Не трогает уже существующие ссылки и теги.
- Включается только для статей длиннее 600 знаков.

**Что это даёт SEO:**
- Глубокие ссылки на коммерческие страницы (МФО, города, суммы) с трафиковых статей.
- Усиление поведенческих факторов (переходы внутри сайта).
- Автоматическая внутренняя структура без ручного труда.
