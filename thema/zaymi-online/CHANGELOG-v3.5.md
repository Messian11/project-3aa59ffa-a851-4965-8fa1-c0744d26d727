# Zaymi Online v3.5.0 — финальные фиксы (полировка)

## 🐛 Исправленные баги

### 1. Бейджи под МФО ломали сетку на десктопе
- «Первый займ 0%», «На карту любого банка», «Деньги за 7 минут на карту» и т.п. теперь обрезаются с многоточием и не переносятся в 2-3 строки.
- Единая высота области заголовка карточки → ровные ряды.
- На мобиле сохранён прежний вид (там и так было ок).

### 2. Фильтр «Особенности» обнулял выдачу
- На `/summa/zaim-100000/` (и других term-страницах) клик на чекбокс выдавал 0 МФО — теперь работает.
- Добавлен fallback: если у МФО не задано поле `mfo_features`, оно вычисляется автоматически из ставки/одобрения/суммы.
- Empty-state «Ничего не найдено» теперь показывает кнопку «Сбросить фильтры».

### 3. Мобильное меню в карточке МФО
- Меню открывается как нормальный fullscreen overlay (не сдвигает контент).
- Клик по ссылке внутри меню закрывает его.
- Body lock — нет двойного скролла.

### 4. Breadcrumbs «Главная › Каталог › Кредито24»
- Теперь идут одной строкой с переносом по словам, а не вертикальной колонкой.
- Компактнее на мобиле.

### 5. Блоки внизу каталога (Займы по сумме / городам / Подборки / С этим ищут)
- Объединены в единые карточки с тенью и скруглениями.
- Тёмный «С этим ищут» переписан на светлый зелёный градиент.
- Pill-теги — единый стиль с hover-анимацией.

## 🎨 Улучшения от себя
- Focus-стейты на всех чекбоксах фильтра (a11y).
- Hover translate-y на pill-тегах.

## 📦 Деплой

1. **Внешний вид → Темы → Загрузить** → `zaymi-online-v3.5-FINAL.zip` → «Заменить активную»
2. **Настройки → Постоянные ссылки** → «Сохранить» (×2)
3. **Ctrl+F5** в браузере, чтобы сбросить кеш CSS

## 📂 Изменённые файлы
- `assets/css/extra.css` — все CSS-фиксы v3.5
- `assets/js/app.js` — закрытие мобильного меню, поддержка нескольких reset-кнопок
- `inc/shortcodes.php` — fallback для features, новый empty-state
- `style.css`, `functions.php` — bump до 3.5.0
