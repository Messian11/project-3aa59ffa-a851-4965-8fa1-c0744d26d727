# Zaymi Online v3.4.0 — Changelog

Дата: 2 мая 2026

## 🐛 Исправлено

### Звёздочки рейтинга наезжали на названия МФО
- Карточки в каталоге (`/mfo/`), на страницах городов, сумм и ситуаций — звёзды больше не лезут поверх длинных названий типа `Кредито24`, `EzaemOnline`, `ProstoZaim`, `CreditPilot`.
- Заголовки получили `word-break` и `min-width: 0`.
- Блок звёзд получил `flex-shrink: 0` и `white-space: nowrap`.
- На экранах < 380px звёзды переносятся под заголовок.

### Картинки в блоке "Свежие статьи блога" на главной
- Шорткод `[zaymi_blog_section]` теперь выводит `the_post_thumbnail()` каждой статьи.
- Добавлен бейдж категории (Гид / Сравнение / Новости).
- Hover-эффект: плавное масштабирование картинки.
- Если у статьи нет featured image — показывается красивый градиентный плейсхолдер.
- Дата публикации в карточке.

### Прочие мелкие фиксы
- Длинные слова в `h1/h2/h3` корректно переносятся.
- Хлебные крошки на term-страницах получили отступ сверху.
- Sticky-CTA больше не перекрывает футер (z-index).
- Добавлен skeleton-loader для карточек МФО.
- Print-стили для статей блога (распечатка без шапки/футера/CTA).
- Фолбэк для `<img>` без src — больше не ломают вёрстку.

## 📦 Установка

1. **Внешний вид → Темы → Добавить новую → Загрузить тему**
2. Выберите `zaymi-online-v3.4-FINAL.zip`
3. Если спросят — нажмите **"Заменить активную тему"**
4. **Настройки → Постоянные ссылки → Сохранить** (2 раза)
5. Очистите кеш браузера (Ctrl + F5) и кеш-плагина если есть

## ✅ Что НЕ менялось
- Цвета, шрифты, дизайн-токены
- Структура CPT, ACF-полей, таксономий
- Аналитика, плагины, SEO
- Программатик-страницы, sitemap

Любые ваши настройки и контент сохраняются — это чисто визуальные правки.
