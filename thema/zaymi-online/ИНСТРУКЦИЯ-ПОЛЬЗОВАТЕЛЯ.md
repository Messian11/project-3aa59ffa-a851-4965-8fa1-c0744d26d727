## 1. Первый запуск и установка

### 1.1 Минимальные требования
- WordPress **6.4+**
- PHP **8.0+** (лучше 8.1 или 8.2)
- MySQL 5.7+ / MariaDB 10.3+
- Хостинг с поддержкой `mod_rewrite` (для ЧПУ-ссылок)
- Свободно ≥ 200 МБ под тему + uploads

### 1.2 Установка темы
1. Скачай ZIP `zaymi-online-v3.2-FINAL.zip`. **Не распаковывай его.**
2. WP-админка → **Внешний вид → Темы → Добавить новую → Загрузить тему**
3. Выбери ZIP → **Установить → Активировать**
4. Появится синий баннер "Тема Zaymi Online активирована" — это нормально.

### 1.3 Установка ACF Pro (обязательно!)
Без ACF не будет работать половина полей МФО.
1. Купи или скачай **Advanced Custom Fields PRO** (https://www.advancedcustomfields.com/pro/)
2. **Плагины → Добавить новый → Загрузить плагин** → ZIP ACF Pro → Установить → Активировать
3. Введи лицензионный ключ в **Custom Fields → Updates** (обновления = новые фишки + безопасность)

### 1.4 Сброс постоянных ссылок (КРИТИЧНО!)
**Настройки → Постоянные ссылки** → выбери "Название записи" → **Сохранить изменения** (нажми **2 раза**).

Это перепрописывает rewrite-правила для:
- `/mfo/{slug}/` — карточки МФО
- `/goroda/{город}/` — страницы городов
- `/summa/{сумма}/` — страницы сумм
- `/situations/{подборка}/` — подборки
- `/go/{slug}/` — клоакинг для CPA
- `/sitemap.xml` — карта сайта

**Если этого не сделать — все эти URL будут отдавать 404.**

### 1.5 Чек-лист после активации
Проверь что в левом меню админки появились:
- ✅ **МФО** (с подменю: Все МФО, Добавить, Города, Суммы, Ситуации, ⚡ Импорт Leads.su)
- ✅ **Заявки**
- ✅ **AI Writer**
- ✅ **Авторы**
- ✅ **Дашборд Zaymi** (наверху)

Если чего-то нет — нажми **Сохранить** в Постоянных ссылках ещё раз.

### 1.6 Демо-контент
Тема **сама** при активации засевает:
- 8 МФО (Займер, Веббанкир, MoneyMan и др.)
- 10 городов (Москва, СПб, Екатеринбург...)
- 6 ситуаций ("Без отказа", "С плохой КИ", "Без проверки"...)
- 9 сумм (от 5000 до 100 000)
- 3 статьи блога

Если по какой-то причине пусто — зайди в **Инструменты → Zaymi Seeder → Запустить засев**.

## 2. Смена логотипа

### Способ 1 — через админку (САМЫЙ ПРОСТОЙ, рекомендую)
1. **Внешний вид → Настроить → Идентичность сайта**
2. Раздел **Логотип** → **Выберите логотип** → загрузи PNG/SVG
3. Рекомендуемый размер: **240 × 60 px**, прозрачный фон
4. **Опубликовать**

### Способ 2 — заменить файл напрямую
1. Через FTP / файловый менеджер хостинга открой: `wp-content/themes/zaymi-online/assets/img/`
2. Замени `logo.png` своим файлом (имя должно остаться **logo.png**)
3. Очисти кеш браузера (Ctrl+F5)

### Способ 3 — через ACF Options (для разных логотипов в шапке/подвале)
1. **Zaymi → Настройки темы** (появляется если активен ACF Pro)
2. Поля **Логотип шапки** / **Логотип подвала** / **Favicon**
3. Загрузи разные изображения → Сохранить

### Favicon (иконка вкладки браузера)
**Внешний вид → Настроить → Идентичность сайта → Иконка сайта** → загрузи квадратный PNG минимум 512×512.

## 3. Главная страница

Главная собирается из шорткодов в обычной странице (Pages → Главная) ИЛИ автоматически через `front-page.php`.

### 3.1 Блоки главной (в порядке сверху вниз)
| Блок | Шорткод | Что показывает |
|---|---|---|
| Шапка с поиском | `[zaymi_hero]` | заголовок + поле "Введите сумму" + ссылки на популярные МФО |
| Соц. доказательства | `[zaymi_social_proof]` | "1 000 000 займов оформлено" + рейтинг |
| Каталог МФО | `[zaymi_catalog limit="6"]` | сетка карточек с фильтром |
| Подборки ситуаций | `[zaymi_situations]` | "Без отказа", "С плохой КИ" и т.д. |
| Города | `[zaymi_cities limit="12"]` | карточки городов |
| Быстрые суммы | `[zaymi_amounts]` | 5к, 10к, 30к, 50к, 100к |
| Как это работает | `[zaymi_how_it_works]` | 3 шага |
| Сравнение | `[zaymi_comparison]` | таблица топ-3 МФО |
| Блог | `[zaymi_blog_grid limit="3"]` | свежие статьи |
| FAQ | `[zaymi_faq]` | вопросы-ответы (с JSON-LD) |
| SEO-хаб | `[zaymi_seo_hub]` | ссылки на популярные категории |
| Подписка | `[zaymi_newsletter]` | форма email |

### 3.2 Как редактировать тексты на главной
**Pages (Страницы) → Главная** → откроется Гутенберг с шорткодами. Можешь:
- менять параметры шорткодов (например `limit="6"` → `limit="9"`)
- добавлять свои абзацы текста между блоками
- удалять ненужные блоки

### 3.3 Как сделать кастомный hero
```
[zaymi_hero
  title="Займ за 5 минут на карту"
  subtitle="100% одобрение, без проверок"
  cta_text="Получить деньги"
]
```

## 4. Карточка МФО

### 4.1 Добавить новую МФО за 5 минут
1. **МФО → Добавить новую**
2. **Название** → "Займер" (или твоё)
3. **Содержимое** → краткое описание (2-3 абзаца)
4. **Изображение записи** (справа) → логотип МФО (квадрат 200×200)
5. Заполни **табы редактора** (внизу под текстом):

#### Таб "📋 Основное"
- **Slug** (для URL) — латиница, по умолчанию из названия
- **Краткое описание** — выводится в карточках каталога
- **CPA-ссылка** — твоя реферальная (Leads.su, Leadgid)
- **Метка** — "Популярное", "Без отказа", "Новое" и т.д.

#### Таб "💰 Тарифы"
Повторяющееся поле:
- Сумма от / Сумма до
- Срок от / Срок до (дни)
- Ставка % в день
- Первый займ бесплатно? (галочка)

#### Таб "✅ Условия"
- Возраст от / до
- Гражданство РФ — да/нет
- Прописка обязательна — да/нет
- Доход подтверждать — да/нет
- Способы получения (Карта, Qiwi, ЮMoney, Наличными...)

#### Таб "❓ FAQ"
Повторяющееся: Вопрос + Ответ. Автоматически попадёт в JSON-LD FAQPage → шанс получить расширенный сниппет в Яндексе/Google.

#### Таб "🔍 SEO"
- **Title** — переопределяет автоматический
- **Description** — для сниппета в выдаче
- **OG image** — картинка для соцсетей (1200×630)
- **Канонический URL** — оставь пустым (заполнится сам)

6. **Категории**: галочки на нужные **Города** / **Ситуации** / **Суммы** (справа)
7. **Опубликовать**

### 4.2 Дублировать МФО
В списке МФО наведи курсор → **Клонировать**. Создаст копию со всеми табами — удобно если МФО похожи.

### 4.3 Массовое редактирование
**МФО → Все МФО** → галочками отметь несколько → **Действия → Изменить → Применить**. Можешь скопом поменять статус, категорию, метку.

### 4.4 Сортировка в каталоге
По умолчанию — по дате. Хочешь по рейтингу или вручную? Включи плагин **Intuitive Custom Post Order** → сможешь таскать мышкой.

## 5. Таксономии (Города / Суммы / Ситуации)

### 5.1 Города (`/goroda/{slug}/`)
**МФО → Города → Добавить**
- **Название** — "Екатеринбург"
- **Slug** — `ekaterinburg` (только латиница!)
- **Описание** — текст для SEO внизу страницы
- **SEO Title / Description** (поля внизу) — для тега `<title>` и meta description

⚠️ **Если оставить описание пустым** — тема сама подставит SEO-плейсхолдер ("Займы в {Город} онлайн на карту..."). Но лучше написать руками 1500-2500 знаков уникального текста.

### 5.2 Суммы (`/summa/{slug}/`)
Точно так же. Slug должен содержать число: `5000`, `10000`, `30000`. Тема по slug понимает сумму и подставляет в FAQ/Schema.

### 5.3 Ситуации (`/situations/{slug}/`)
Например: "без-отказа", "с-плохой-ки", "без-проверки", "пенсионерам", "студентам".

### 5.4 Что писать в SEO-описание категории
**Хорошая структура (1500-2500 знаков):**
1. Вступление (200 знаков): "В нашем каталоге собраны проверенные МФО, выдающие займы в {Город}..."
2. Список преимуществ (3-5 пунктов)
3. Как оформить (пошагово)
4. Какие документы нужны
5. Что делать при отказе
6. FAQ (2-3 вопроса) — попадут в Schema автоматически

## 6. Блог и AI Writer

### 6.1 Создать статью вручную
**Записи → Добавить новую**. Стандартный Гутенберг.

**Обязательно заполни:**
- Изображение записи (1200×675)
- Категория и метки
- **Автор** — выбери из CPT zaymi_author (см. раздел 7)
- В тексте используй шорткоды:
  - `[zaymi_related_mfo limit="3"]` — блок похожих МФО
  - `[zaymi_lsi]` — LSI-облако ключей
  - `[zaymi_related_posts]` — "Читайте также"

### 6.2 AI Writer — настройка автогенерации

**AI Writer → Настройки**

#### Провайдер
- **OpenAI** (рекомендую) — модель `gpt-4o` или `gpt-4o-mini` (дешевле)
- API-ключ → https://platform.openai.com/api-keys

#### Картинки
- **DALL·E 3** (1024×1024) — ~$0.04 за картинку
- Или **бесплатная заглушка** (галочка "Не генерировать картинки")

#### Расписание автопостинга
**AI Writer → Расписание**
- Частота: каждые 12 / 24 / 48 часов
- Время суток (по МСК): 09:00, 14:00, 19:00 — лучше всего для индексации Яндексом
- Темы: список ключей (по одному в строке)

#### Очередь
**AI Writer → Очередь** — видишь что в плане, можешь удалить/отложить.

#### Лог
**AI Writer → Лог** — что сгенерировалось, какие ошибки. Если "API rate limit" — значит уперся в лимит OpenAI, подожди час.

### 6.3 Стоимость одной статьи
- GPT-4o-mini + 1 картинка DALL·E 3: ~**$0.10** = ~10 ₽
- GPT-4o + 1 картинка: ~**$0.30** = ~30 ₽

**100 статей в месяц = 1000-3000 ₽** на API.

### 6.4 Качество AI-контента
**ВАЖНО:** AI пишет неплохо, но всегда **прочитай и отредактируй** перед публикацией:
- Проверь факты (ставки МФО, законы, цифры)
- Уберай "воду" ("в современном мире...", "как известно...")
- Добавь свои примеры

Иначе Яндекс заминусует за "малополезный контент" (фильтр Минусинск/АГС).

## 7. Авторы-эксперты

Зачем: Яндекс/Google любят сайты с **E-E-A-T** (экспертность, авторитетность, доверие). Особенно для финансовой ниши (YMYL — Your Money Your Life).

### 7.1 Создать автора
**Авторы → Добавить нового**
- ФИО — "Анна Петрова"
- Должность — "Финансовый аналитик, 8 лет опыта"
- Биография — 200-400 знаков
- Аватар — фото 400×400
- Соц. сети (опционально)

### 7.2 Сгенерировать автора через AI
**Авторы → Сгенерировать AI** → выбери специализацию ("эксперт по МФО", "юрист по 353-ФЗ") → жми "Создать". AI напишет биографию + DALL·E нарисует аватар.

⚠️ Использование AI-аватаров в России **легально**, но в био укажи "образ создан с помощью ИИ" — для прозрачности.

### 7.3 Привязать к статье
В редакторе статьи (Гутенберг) → справа блок **Автор Zaymi** → выбрать. Автоматически добавится JSON-LD `Person` + блок "Об авторе" внизу статьи.

## 8. Заявки и CRM

### 8.1 Где смотреть лиды
**Заявки** в левом меню. Видно:
- Дата и время
- ФИО, телефон, email
- Сумма, срок
- С какой страницы / города
- UTM-метки
- Статус (новая / в работе / отказ / выдан)

### 8.2 Экспорт в CSV
**Заявки → Экспорт CSV** → скачается файл за выбранный период.

### 8.3 Webhook на Telegram
1. Создай бота через @BotFather → получи токен
2. Узнай свой chat_id через @userinfobot
3. **Заявки → Настройки → Telegram** → введи токен и chat_id
4. Каждый новый лид моментально приходит в Telegram

### 8.4 Webhook на Bitrix24 / amoCRM
**Заявки → Настройки → Webhook URL** → вставь URL входящего вебхука твоей CRM. Формат отправки — JSON.

### 8.5 Проверка спама
Встроена reCAPTCHA v3 (невидимая). Ключи: **Настройки → Zaymi → reCAPTCHA**. Получить — https://www.google.com/recaptcha/admin

## 9. Импорт Leads.su

### 9.1 Получить токен
1. Зарегистрируйся на https://leads.su
2. Подайся на офферы из категории "МФО / Займы" (Займер, MoneyMan, Веббанкир и т.д.)
3. После аппрува — https://webmaster.leads.su/tools/api → создай API-токен

### 9.2 Настроить импорт
**МФО → ⚡ Импорт Leads.su**
- **API токен** → вставь
- **Категория** → "МФО" (id из списка)
- **Только активные офферы** → ✅
- **Автообновление** → раз в сутки (галочка)

### 9.3 Запустить
Кнопка **"Импортировать сейчас"** → подтянет все аппрувленные офферы:
- Название → в title МФО
- Описание → в content
- Логотип → в featured image
- Ставка/сумма/срок → в ACF поля
- CPA-ссылку → в поле "CPA URL"

### 9.4 Что делать если оффер отклонён
- В админке Leads.su посмотри причину отказа (часто — нет трафика)
- Подавайся повторно через 2 недели когда у сайта появится посещаемость
- Параллельно работай с **Leadgid** и **Salid** — там аппрув проще

### 9.5 Альтернативные CPA-сети
Тема готова к ручному добавлению любой CPA. Просто в карточке МФО → поле "CPA URL" → вставь свою партнёрскую ссылку.

Топ сетей по займам (РФ):
- Leads.su — самая большая, но строгий аппрув
- Leadgid.ru — лояльнее к новичкам
- Salid.ru — много эксклюзивов
- Mafin.ru — прямые офферы от МФО

## 10. SEO

### 10.1 Где править Title и Description страницы
**Для МФО:** в карточке МФО → таб "🔍 SEO"
**Для Городов/Сумм/Ситуаций:** в редакторе термина → поля SEO внизу
**Для статей:** через плагин Yoast SEO или Rank Math (если установлен) либо в кастомных полях темы
**Для главной:** **Zaymi → Настройки темы → Главная страница SEO**

Если поле пустое — генерируется автоматически по шаблону.

### 10.2 Schema.org (микроразметка)
Тема **сама** добавляет JSON-LD:
- `Organization` — на главной (название сайта, лого, соцсети)
- `FinancialService` + `FinancialProduct` — на странице МФО (со ставками, рейтингом)
- `BreadcrumbList` — на всех страницах
- `FAQPage` — где есть FAQ-блок
- `Article` + `Person` (автор) — на статьях
- `AggregateRating` — на МФО с отзывами

Проверить можно тут: https://search.google.com/test/rich-results

### 10.3 OG-картинки (для соцсетей)
Тема генерирует автоматически если у записи есть Featured Image. Размер — 1200×630.

Для главной можно задать в **Zaymi → Настройки темы → Соцсети → OG image по умолчанию**.

### 10.4 Sitemap
- `https://твой-сайт.ru/sitemap.xml` — главная карта
- `https://твой-сайт.ru/sitemap-mfo.xml` — только МФО
- `https://твой-сайт.ru/sitemap-cities.xml` — только города
- `https://твой-сайт.ru/sitemap-articles.xml` — только статьи

### 10.5 IndexNow (быстрая индексация в Яндексе и Bing)
1. **Zaymi → Настройки → IndexNow** → сгенерируй ключ (кнопка)
2. Тема сама пингует поисковики при публикации/обновлении
3. Проверь в Яндекс.Вебмастере → "Индексирование → Переобход страниц" — должны появляться запросы

### 10.6 Yandex Webmaster API (автоотправка)
**Zaymi → Настройки → Yandex API** → введи OAuth-токен (получить: https://oauth.yandex.ru/). Тема будет отправлять новые URL в очередь переобхода.

### 10.7 robots.txt
Генерируется динамически. Чтобы проверить → открой `https://твой-сайт.ru/robots.txt`

Должны быть строки:
```
Allow: /mfo/
Allow: /goroda/
Allow: /summa/
Allow: /situations/
Sitemap: https://твой-сайт.ru/sitemap.xml
```

## 17. Бэкапы и обновления

### 17.1 Что бэкапить
- **База данных** (`wp_*` таблицы) — каждый день
- **wp-content/uploads** — раз в неделю
- **wp-content/themes/zaymi-online** — раз в месяц или после твоих правок

### 17.2 Плагины для авто-бэкапа
- **UpdraftPlus** (бесплатный, с выгрузкой в Google Drive / Yandex Disk)
- **WPvivid Backup** — альтернатива
- **All-in-One WP Migration** — полная копия одним файлом (для переезда на новый хостинг)

### 17.3 Перед обновлением WP / плагинов
1. Сделай бэкап
2. Обновляй сначала на тестовом сайте (если есть)
3. После обновления — проверь главную, карточку МФО, форму заявки

### 17.4 Обновление темы Zaymi Online
Когда выйдет новая версия:
1. Бэкап!
2. **Внешний вид → Темы → Добавить новую → Загрузить** → новый ZIP
3. WordPress спросит "Заменить?" → **Да**
4. Активировать новую → **Постоянные ссылки → Сохранить**

⚠️ Если правил файлы темы напрямую (`functions.php` и т.д.) — твои правки сотрутся. Используй **дочернюю тему** для кастомизации.

### 17.5 Создать дочернюю тему
1. Создай папку `wp-content/themes/zaymi-online-child/`
2. Внутри файл `style.css`:
```css
/*
Theme Name: Zaymi Online Child
Template: zaymi-online
Version: 1.0
*/
```
3. Файл `functions.php`:
```php
<?php
add_action('wp_enqueue_scripts', function() {
    wp_enqueue_style('parent-style', get_template_directory_uri().'/style.css');
});
```
4. **Внешний вид → Темы → Активировать "Zaymi Online Child"**

## 18. FAQ — Частые проблемы

### 404 на странице МФО
→ **Настройки → Постоянные ссылки → Сохранить**

### 404 на /goroda/{город}/
→ Тоже сохрани постоянные ссылки. Если не помогло — slug города должен быть латиницей (не "екатеринбург" а "ekaterinburg")

### "Ошибка установки menu locations"
→ **Внешний вид → Меню → Управление местами** → назначь меню в позиции

### AI Writer не работает
→ Проверь API-ключ OpenAI (баланс на счёте, лимиты)
→ Лог: **AI Writer → Лог**

### Заявки не приходят на email
→ WordPress по умолчанию шлёт через PHP mail() — часто блокируется хостингом
→ Поставь плагин **WP Mail SMTP** + Yandex SMTP / Mailgun / SendGrid

### Сайт медленный
→ Включи кеширование: плагин **WP Super Cache** или **LiteSpeed Cache**
→ Сожми картинки: **ShortPixel** / **Imagify**
→ Включи Lazy Loading (встроен в WP 5.5+, проверь что не отключен)
→ Хостинг должен быть с PHP 8.1+ и SSD

### Кириллица в URL
→ slug всегда пиши латиницей: "москва" → "moskva"
→ Плагин **Cyr-To-Lat** автоматически транслитерирует

### Не индексируется в Яндексе
→ Я.Вебмастер → добавь сайт → подтверди → отправь sitemap
→ Подожди 2-4 недели для первичной индексации
→ Включи IndexNow (см. раздел 10.5)

### Не индексируется в Google
→ Google Search Console → Property → Sitemap → добавь
→ "Inspect URL" → "Request Indexing" — для важных страниц

### Дубли страниц с / и без / на конце
→ В **Настройках → Постоянные ссылки** оставь "/" в конце шаблона
→ Тема ставит canonical автоматически

### Реферальные ссылки попадают в индекс Google
→ Тема использует **/go/{slug}/** редиректы с rel=nofollow + noindex в robots — должно быть ок
→ Проверь robots.txt: должна быть строка `Disallow: /go/`

### Лимит OpenAI закончился посреди дня
→ Поставь биллинг с авто-пополнением на $10 — хватит на 200+ статей

### Не открывается /sitemap.xml
→ Сохрани постоянные ссылки
→ Если стоит Yoast SEO — он перебивает наш sitemap. Отключи sitemap в Yoast: **SEO → Общие → Возможности → XML карты сайта → Off**

### Конфликт с другим SEO-плагином
→ Тема дружит с Yoast / Rank Math / All in One SEO, но они дублируют JSON-LD
→ В настройках плагина отключи: Schema, OG-теги, Breadcrumbs, Sitemap (всё это уже делает тема)

### Карточки МФО все одинакового цвета
→ Вкладка "Основное" → поле "Акцентный цвет" — задай HEX (например `#10b981`)

### Не работает экспорт CSV заявок
→ Проверь что у юзера роль admin или editor
→ Хостинг может блокировать большие выгрузки — сократи диапазон дат

### Логотип не меняется
→ Очисти кеш браузера (Ctrl+F5) и кеш плагина (если стоит)
→ Если использовал FTP — проверь что файл точно `logo.png` (не logo.jpg, не Logo.png)

### "Maximum execution time" при импорте Leads.su
→ Хостинг режет долгие запросы. В .htaccess добавь:
```
php_value max_execution_time 300
```

### Реклама в WP-админке
→ Это от плагинов. **Плагины → Все** → отключи лишнее (Hello Dolly, Akismet если не используешь)

### Не работают шорткоды (выводятся как текст)
→ Проверь что тема активна
→ Очисти кеш страниц
→ В Гутенберге используй блок "Шорткод", не "Абзац"

### Дашборд показывает нули
→ Подключи Метрику API (раздел 16.2)
→ Подожди 24 часа после первой настройки

### Нет авторов в выпадашке статьи
→ Создай хотя бы одного: **Авторы → Добавить нового**

### Ошибка на странице города
→ Проверь slug города (только латиница)
→ Очисти кеш
→ Сохрани постоянные ссылки

### Ошибка 500 после активации
→ Скорее всего PHP < 8.0. Зайди в панель хостинга → переключи PHP на 8.1
→ Если не помогло — включи debug в `wp-config.php`: `define('WP_DEBUG', true);` и смотри что в логе
